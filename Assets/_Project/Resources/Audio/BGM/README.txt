LootUp BGM Prototype Pack
============================

Files
- LootUp_Title_Loop.wav          : 104 BPM, title screen
- LootUp_Lobby_Loop.wav          : 112 BPM, lobby/menu
- LootUp_InGame_Normal_Loop.wav  : 132 BPM, normal gameplay
- LootUp_InGame_Fever_Loop.wav   : 160 BPM, fever mode

Format
- WAV PCM 16-bit stereo
- 22,050 Hz
- Instrumental electronic/chiptune prototype
- Designed as bar-aligned loop material

Unity import recommendation
1. Select each WAV in Project.
2. Load Type: Compressed In Memory
3. Compression Format: Vorbis
4. Quality: 70-80
5. Enable Preload Audio Data.
6. AudioSource: Loop ON, Play On Awake as needed.
7. For Normal/Fever transitions, use two AudioSources and a 0.3-0.5 second crossfade.

Note
These are original synthesized prototype tracks generated for the LootUp project.
For final commercial mastering, consider replacing or mastering the sound set while preserving BPM, structure, and melodic identity.
