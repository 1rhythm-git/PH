## 기본 원칙
- 보고/설명은 한국어로 작성한다.
- 코드 주석(//, /* */)은 한국어로 작성한다.
- 되묻기는 최소화한다. 불확실한 정보는 “가정”으로 처리하고, 마지막에 체크리스트로 확인 항목을 제시한다.
- 사용자가 요청하지 않은 기존 기능/로직은 삭제/변경하지 않는다.

## 입력(사용자 제공 정보가 없으면 가정)
- 목표(무엇을 달성하려는지)
- 현재 동작/상태(무슨 문제가 발생하는지)
- 기대 동작(원하는 정상 동작)
- 관련 스크립트/로그/재현 절차(있으면 활용)

## Unity 특화 체크 항목(상황에 맞는 것만 포함)
- NullReference 원인(SerializeField 누락/씬 참조 끊김)
- Update/Coroutine 중복 실행 여부
- Time.timeScale 영향 여부
- Physics/Trigger 레이어 매트릭스 설정
- Input System / Old Input 혼용 이슈
- Scene 전환 시 오브젝트 파괴/중복 생성(DontDestroyOnLoad)
