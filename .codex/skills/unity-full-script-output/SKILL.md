## 언제 사용하나
- 사용자가 “통합본”, “전체 코드”, “전체 스크립트”, “전체 파일 보여줘”를 요구할 때
- 또는 수정 범위가 커서 부분 패치보다 전체가 안전할 때

## 필수 규칙(절대 준수)
- 출력/설명은 한국어.
- 코드 주석은 한국어.
- 기존 public 필드/enum/클래스/메서드 이름은 가능한 유지.
- 사용자가 요청하지 않은 기능 삭제 금지.
- 기존 로직을 바꿔야 하면: 변경 이유 + 영향 범위 + 대체 로직을 먼저 요약.

## 통합본 출력 규칙
- 해당 C# 파일을 “처음부터 끝까지 전체” 출력한다.
- 누락/생략/중간 생략(...) 금지.
- 변경된 부분에만 주석 태그를 붙인다:
  - (추가) 새로 추가한 코드
  - (변경) 기존 코드를 수정한 코드
  - (주의) 기존 동작에 영향을 줄 수 있는 부분

## 결과 보고 포맷
1) 변경 요약(3~7줄)
2) 영향 범위(무엇이 바뀌고/안 바뀌는지)
3) 통합본 코드(전체 파일)
4) Inspector/Scene 세팅 변경이 있으면 단계별 안내
5) 테스트 체크리스트(회귀 포함)

## 추가 가드레일
- Unity 자동 생성 폴더(Library/Temp/Logs 등)는 수정하지 않는다.
- 가능한 컴파일 에러(네임스페이스, using, 접근 제한) 징후를 스스로 점검하고 마무리한다.
