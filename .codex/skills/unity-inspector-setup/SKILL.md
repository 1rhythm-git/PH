## 목적
코드는 맞는데 “씬/인스펙터 세팅 누락”으로 동작이 안 되는 문제를 줄인다.

## 필수 규칙
- 설명은 한국어.
- 코드 주석은 한국어.
- 실제 프로젝트 구조(이미 존재하는 오브젝트/프리팹)를 우선한다.
- 되묻기 최소화: 불확실하면 가정하고, 마지막에 확인 체크리스트 제공.

## 출력 포맷(항상 고정)
1) 붙일 대상(어느 GameObject?)
- 계층 경로 예시: Canvas/TopUI/...
- 없다면 새로 만들기 단계 포함

2) 붙일 컴포넌트(어떤 스크립트/컴포넌트?)
- Add Component로 추가할 것
- 이미 붙어있다면 “중복 추가 금지” 명시

3) Inspector 필드 세팅(표로 또는 목록으로)
- [필드명] = (어디 오브젝트를 드래그?) / (값은 얼마?)
- 참조 필드(null 가능성) 우선 점검

4) 씬/프리팹 적용 순서(실수 방지)
- 프리팹이면 Apply 해야 하는지
- 런타임 생성이면 Awake/Start 타이밍 주의

5) 검증 체크리스트
- Play 모드에서 확인할 UI/로그
- 특정 이벤트(충돌/버튼) 재현 절차
